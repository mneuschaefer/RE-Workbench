# Templates

Use [User story](User%20story.md) or [Use case](Use%20case.md) as a starting point under `1 Working files`. Remove sections that add no useful information. Leave unanswered questions visible instead of filling them with guesses.

Enable Obsidian's core Templates plugin and set this folder as its template location, or copy the content manually. Creating a local note does not create a Confluence page.

These templates illustrate the example RE skills. Replace or adapt them to the project's own terminology, required fields and review criteria. They are not a prescribed requirements standard.
